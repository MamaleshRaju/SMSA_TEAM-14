# Dataset Description

## Dataset Name
Social Media Engagement Dataset

## Source
https://www.kaggle.com/datasets/subashmaster0411/social-media-engagement-dataset

## Description
This dataset contains social media posts along with engagement metrics such as likes, shares, comments, and sentiment-related information.

## Number of Instances
12000

## Number of Attributes
28

## Important Attributes
- text_content → social media post content  
- sentiment_label → Positive, Negative, Neutral  
- likes_count → number of likes  
- shares_count → number of shares  
- comments_count → number of comments  
- impressions → reach of the post  
- engagement_rate → user interaction level  

## How to Download
1. Go to the Kaggle link above  
2. Download the dataset  
3. Place it inside the `data/` folder as:
   social_media_engagement.csv  

## Note
Dataset is not uploaded to GitHub due to size and public availability.
